## ⚙️ 使用说明

### 手动更新统计
1. 进入 GitHub Actions 页面
2. 选择 "Update Contribution Stats"
3. 点击 "Run workflow"

### 自动触发
- 当统计脚本更新时自动触发
- 主分支有变更时需手动触发

### 本地查看
```bash
# 切换到统计分支
git checkout contrib-stats

# 查看统计报告
# 用浏览器打开 docs/index.md
```
